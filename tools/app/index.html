Not connected

Plug your Phob into a GameCube adapter and press Use adapter.

A Lossless adapter or Nintendo's, any port. Close Dolphin first: only one program can read the adapter.

  • Calibrate either stick, one step at a time. The app shows the Phob's target and where your stick lands in Melee coordinates.
  • Tune snapback. Flick the stick, see how far it swings past center, and get the exact buttons to press to fix it.
  • Check notches against Melee's coordinates, the way GTS shows them, with no Dolphin and no config ROM.
  • Tournament check. Stick reach and triggers measured against the controller ruleset events cite, in a report you can show a TO.

The Phob tools are in the techchase desktop app. A browser can't open a GameCube adapter.

Have a GC Ultimate?

Plug it in with a USB cable and press Connect controller. Chrome or Edge will list it; pick it and press Connect.

  • The controller must run the techchase firmware. On official firmware the app can still read it, but can't remap.
  • Close gcu.py, HHL's web app and Dolphin first: only one program can talk to the controller at a time.
  • In Slippi mode the controller is a plain GameCube adapter, so connect it with Use adapter instead.

            does…

            Picking the button’s own job puts it back to default. To swap two buttons, change both.

            Remap without a computer (Quick Remap)
            1. Hold Power + Start for 1.5 s. The LED pulses purple and the controller ticks once; the game sees the controller at rest.
            2. Press the button you want to change (one tick), then the button whose job it should do (two ticks, green flash). Saved at once.
            3. Hold Start for 3 s to reset every button (orange flash).
            4. Tap Power to finish (or leave it alone for 20 s).

            Profiles

            Save your layouts, one per game or character, and load them in a click. Profiles live in this browser; export them to keep a copy or move them to another device.

              USB mode (until unplugged)

              The controller restarts its USB connection in the new mode. Your browser may ask you to pick it again.

              Dolphin

              For Melee, put the controller in Slippi mode and set the Dolphin port to GameCube Adapter for Wii U. Dolphin does no button mapping there, so your remaps reach the game exactly as set. A Standard Controller port maps buttons by number, and has to match the controller's numbers in SInput mode.

              Going back to official firmware

              1. Unplug the controller. Hold ZL + Start and plug it in: a drive appears.
              2. Drag the official gcu_r4k.uf2 onto it. The controller restarts on its own.
